# OrnaMap

OrnaMap - школьный исследовательский проект по информатике о цифровой работе с северными орнаментами.

Приложение работает с двумя типами визуальных мотивов:

- полосной красно-синий орнамент, похожий на вышивку или декоративную ленту;
- отдельные черные знаки и рисунки, которые можно выбирать по одному и накладывать на макеты.

## Идея проекта

Меня всегда интересовали национальные узоры и орнаменты, особенно северные мотивы, связанные с Кольским полуостровом, где я живу и учусь. В орнаменте можно увидеть не только красоту, но и связь с историей, природой и культурой места.

Я решила создать веб-сервис для дизайнеров и школьников, который помогает быстро проверить, как орнамент будет смотреться на разных предметах. Такой сервис может быть полезен при создании макетов сувениров, плакатов, блокнотов или текстиля.

## Что умеет приложение

- создает полосной орнамент по референсу;
- содержит набор отдельных знаков по второму референсу;
- позволяет выбрать отдельный знак и повторить его на макете;
- позволяет загрузить свой орнамент;
- содержит готовые макеты: шоппер, блокнот, плакат, футболка и кружка;
- позволяет загрузить свой макет и настроить область наложения;
- находит основные цвета изображения с помощью метода KMeans;
- выделяет контуры узора;
- создает повторяющийся паттерн;
- позволяет скачать результат в формате PNG.

## Почему это информатика

В проекте используются темы из информатики:

- обработка цифрового изображения как массива пикселей;
- компьютерное зрение: выделение контуров;
- начальный уровень машинного обучения: кластеризация цветов методом KMeans;
- программная сборка изображения из нескольких слоев;
- создание веб-приложения на Python и Streamlit.

## Быстрый запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

После запуска приложение откроется в браузере. Без загрузки файлов можно пользоваться готовым полосным орнаментом, отдельными знаками и встроенными макетами.

## Для жюри

Проект сделан так, чтобы им можно было воспользоваться прямо на защите: выбрать тип узора, выбрать знак, изменить настройки, загрузить свой макет и сразу увидеть результат.
