# OrnaMap AR

OrnaMap AR - школьный исследовательский проект по информатике о генерации северных орнаментов и их примерке на реальную поверхность.

## Идея проекта

Меня всегда интересовали национальные узоры и орнаменты, особенно северные мотивы, связанные с Кольским полуостровом. Я решила сделать веб-приложение, которое не просто показывает готовый рисунок, а помогает создать новый орнамент и сразу увидеть, как он будет выглядеть на макете или фотографии.

Главная идея новой версии - генератор узоров и примерка в стиле дополненной реальности. Пользователь выбирает стиль, палитру, плотность и номер варианта, а программа создает орнамент и накладывает его на плоскость с перспективой.

## Что умеет приложение

- генерирует новые орнаменты из простых северных мотивов;
- поддерживает стили: пиксельная вышивка, петроглифы и северная мозаика;
- меняет палитру, плотность, симметрию и номер варианта;
- строит полосную версию узора для ткани или бордюра;
- находит основные цвета изображения методом KMeans;
- показывает выделение контуров;
- накладывает узор на поверхность с перспективным преобразованием;
- работает с готовой демо-сценой, загруженной фотографией или снимком с камеры;
- позволяет скачать результат и сам орнамент в формате PNG.

## Почему это информатика

В проекте используются темы из информатики:

- изображение хранится и обрабатывается как массив пикселей;
- программа генерирует графику по алгоритму и параметрам пользователя;
- используется компьютерное зрение: выделение контуров;
- используется начальный уровень машинного обучения: кластеризация цветов KMeans;
- используется геометрическое преобразование изображения для AR-эффекта;
- интерфейс сделан как веб-приложение на Python и Streamlit.

## Быстрый запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

После запуска можно пользоваться приложением без дополнительных файлов: демо-сцена и генератор уже встроены. Для AR-режима можно загрузить свое фото или сделать снимок через камеру.
