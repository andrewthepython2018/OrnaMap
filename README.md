# OrnaMap Vision

OrnaMap Vision - школьный исследовательский проект по информатике о компьютерном зрении и цифровой работе с орнаментами.

## Идея проекта

Меня всегда интересовали национальные узоры и орнаменты, особенно северные мотивы, связанные с Кольским полуостровом. В новой версии я решила не делать простую примерку на макет, а показать более сильную задачу: как программа может сама увидеть элементы орнамента на изображении.

Пользователь загружает изображение узора или выбирает встроенный пример. Приложение отделяет узор от фона, находит контуры, вырезает отдельные элементы и собирает из них новые композиции.

## Что умеет приложение

- строит маску изображения и отделяет орнамент от светлого фона;
- находит контуры элементов с помощью OpenCV;
- вырезает найденные фрагменты на прозрачном фоне;
- определяет палитру орнамента методом KMeans;
- оценивает примерную повторяемость полосного узора;
- показывает весь путь анализа: исходник, маска, контуры, палитра;
- генерирует новые композиции из найденных элементов: ленту, тканевый паттерн и круговой орнамент;
- позволяет скачать результаты в PNG.

## Почему это информатика

В проекте используются темы из информатики:

- изображение представляется как массив пикселей;
- используется бинаризация и морфологическая обработка маски;
- OpenCV ищет внешние контуры объектов;
- KMeans группирует похожие цвета;
- программа собирает новое изображение из найденных фрагментов;
- интерфейс сделан как веб-приложение на Python и Streamlit.

## Быстрый запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

В приложении уже есть два встроенных примера: лист отдельных знаков и полосной орнамент. Также можно загрузить свое изображение.

## Для защиты

Короткая формулировка: я создала веб-приложение, которое с помощью компьютерного зрения распознает элементы орнамента и использует их как цифровой материал для создания новых узоров.

На защите удобно показать весь процесс по шагам: исходное изображение, маска, контуры, вырезанные элементы, палитра и новые сгенерированные орнаменты.
